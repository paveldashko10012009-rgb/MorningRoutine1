# Утренний Telegram-бот

Каждый день в 5:01 присылает «доброе утро» и план тренировки с чек-листом.
В дни отдыха — только приветствие и пометка дня.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запусти бота один раз, чтобы узнать свой CHAT_ID:
   ```bash
   export BOT_TOKEN="токен_от_BotFather"
   python bot.py
   ```
   Напиши боту `/start` — он ответит твоим CHAT_ID. Останови бота (Ctrl+C).
4. Запусти уже с CHAT_ID и своим часовым поясом:
   ```bash
   export BOT_TOKEN="токен_от_BotFather"
   export CHAT_ID="123456789"
   export TZ_NAME="Europe/Moscow"
   python bot.py
   ```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BOT_TOKEN` | — (обязательно) | токен бота |
| `CHAT_ID` | — | твой чат; без него рассылка не включается |
| `TZ_NAME` | `Europe/Moscow` | часовой пояс (например `Asia/Almaty`) |
| `SEND_HOUR` / `SEND_MINUTE` | `5` / `1` | время отправки |
| `STATE_FILE` | `state.json` | где хранятся отметки |

## Команды

- `/workout` — прислать план на сегодня прямо сейчас (удобно для проверки)
- `/start` — показать CHAT_ID

## Важно

Бот должен работать 24/7, иначе в 5:01 он ничего не отправит. Подойдёт любой
дешёвый VPS, Raspberry Pi или хостинг вроде Railway / Fly.io. Для постоянной
работы на Linux-сервере можно запустить через `systemd` или `screen`/`tmux`.

## Как поменять план

Все упражнения лежат в начале `bot.py` в словаре `WORKOUTS`, расписание по
дням — в `SCHEDULE` и `REST_DAYS`.
